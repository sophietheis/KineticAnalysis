# Translation kinetic analysis

`KineticAnalysis` is a Python package to estimate kinetic of translation based on fluorescence track.

This project allows you to analyse tracks or generate artificial tracks to test conditions.

This package can be installed, or a user interface is provided through Docker. 


This project is a collaboration between [Mounia Lagha's](http://www.laghalab.com/) and [Tim Saunders'](https://mechanochemistry.org/Saunders/MainSite/Saunders_lab_v4_3.htm) teams. 

## Installation
### Python method
We recommend to create an environment to install `KineticAnalysis` package. 

The recommended way to install `KineticAnalysis` is via [pip](https://pypi.org/project/pip/).

To install all dependencies:
```sh
pip install --no-cache-dir -r requirements.txt
```

To install the latest development version, clone this repository and run:
```sh
pip install .
```


### Docker method
See [docker install](https://github.com/sophiets/KineticAnalysis/doc/Install_docker_kineticapp.pdf)
